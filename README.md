# T'Nature, aperçu du nouveau site

Aperçu du nouveau site de **T'Nature**, gîte et maison d'hôtes dans le village classé
de Château-Chalon (Jura), en cours de relecture avant mise en ligne.

→ **<https://boyernathan39000-max.github.io/tnature/>**

Cet aperçu est fermé aux moteurs de recherche (`noindex` et `robots.txt`) : il ne doit
pas prendre la place du site définitif le jour de sa mise en ligne. Le nom de domaine
reste à arrêter avec la cliente.

Ce dépôt ne contient que le site produit. Les sources, la chaîne de traitement des
images et la documentation de travail sont conservées par l'agence.
